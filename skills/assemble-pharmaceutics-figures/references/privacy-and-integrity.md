# Privacy and scientific integrity

Read source images locally and keep them unchanged. Generated content must stay under `D:\assemble-pharmaceutics-figures`.

Cloud vision is panel-specific and opt-in: set `cloud_vision_authorized: true`, inspect the exact generated `panel-###.jpg` previews, and explicitly acknowledge that their visible text/content is safe to transport before giving the separate `UPLOAD` confirmation. These are resized previews with local filenames removed. They are not anonymized: visible pixels and text remain, and no OCR redaction is implemented. Never send source paths, filenames, project names, authors, or unreviewed sensitive text/content. Cloud output may describe visible image type only; scientific meaning remains unconfirmed.

Never modify pixels, crop blots, guess groups/statistics, upload a directory through blanket consent, or log API keys/base64 data.
